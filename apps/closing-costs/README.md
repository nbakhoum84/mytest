# Closing Costs BC

Expo app: BC closing cost estimator (property transfer tax, legal, inspection, appraisal) and a home-buyer checklist.

```
npm install
npx expo start   # scan with Expo Go
npm test         # unit tests for the cost maths
```
Estimates only; confirm figures with your lawyer.

## Web version
`web/closing-costs/` is a no-install web app (PWA) with the same features. It is deployed by `.github/workflows/pages.yml`; see `site-snippet/install-app-banner.html` for the banner that links to it.
