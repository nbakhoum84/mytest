# Monthly market refresh for White Rock, Abbotsford, Burnaby, Coquitlam, Delta, Langley, New Westminster, Port Coquitlam and Port Moody (automatic publishing)

The page's Edit Page → **Page Script** field contains a small loader (`white-rock-market-loader.txt`; the Lofty Embed box strips `<script>` tags, so it cannot go there). It reads `tools/market-refresh/data/market.json` from this public repo
(`raw.githubusercontent.com`, branch `claude/practical-wozniak-s89tdk`) and fills in every number marked `data-wr`.
The numbers written in the HTML are the fallback if JavaScript or the feed is unavailable.

**One-time setup:** (1) paste `white-rock-listings-code.txt` into the Lofty Embed → CODE box (Update Code); (2) paste `white-rock-market-loader.txt` (JavaScript only, no `<script>` tags) into Edit Page → Page Script; (3) Save and Publish.
After that, pushing a new `market.json` updates the live page (within about 5 minutes, the GitHub cache time). No Lofty login, no re-paste.

```bash
node tools/market-refresh/refresh.js [whiterock|abbotsford|burnaby|coquitlam|delta|langley|newwestminster|portcoquitlam|portmoody]   # collect data (~1 min White Rock, ~5 min Abbotsford; needs Playwright)
python3 tools/market-refresh/build.py [whiterock|abbotsford|burnaby|coquitlam|delta|langley|newwestminster|portcoquitlam|portmoody]  # write the city's market.json + rebuild its code files; optional date arg, --force
```

White Rock: feed `data/market.json`, loader `white-rock-market-loader.txt`, page code `white-rock-listings-code.txt`.
Abbotsford: feed `data/abbotsford/market.json`, loader `abbotsford-market-loader.txt`, page code `abbotsford-listings-code.txt`.
Burnaby: feed `data/burnaby/market.json`, loader `burnaby-market-loader.txt`, page code `burnaby-listings-code.txt` (page copy generated by `tools/page-build/burnaby_page.py`).
Coquitlam: feed `data/coquitlam/market.json`, loader `coquitlam-market-loader.txt`, page code `coquitlam-listings-code.txt` (page copy generated by `tools/page-build/city_page.py coquitlam`).
Delta: feed `data/delta/market.json`, loader `delta-market-loader.txt`, page code `delta-listings-code.txt` (page copy generated by `tools/page-build/city_page.py delta`).
Langley: feed `data/langley/market.json`, loader `langley-market-loader.txt`, page code `langley-listings-code.txt` (page copy generated by `tools/page-build/city_page.py langley`).
New Westminster: feed `data/newwestminster/market.json`, loader `new-westminster-market-loader.txt`, page code `new-westminster-listings-code.txt` (page copy generated by `tools/page-build/city_page.py newwestminster`).
Port Coquitlam: feed `data/portcoquitlam/market.json`, loader `port-coquitlam-market-loader.txt`, page code `port-coquitlam-listings-code.txt` (page copy generated by `tools/page-build/city_page.py portcoquitlam`).
Port Moody: feed `data/portmoody/market.json`, loader `port-moody-market-loader.txt`, page code `port-moody-listings-code.txt` (page copy generated by `tools/page-build/city_page.py portmoody`).
Paste each loader into that page's Edit Page > Page Script (JavaScript only).

- Active listings: counted from the live `/white-rock-listings` results (all pages). Sold data: Lofty `/snapshot` API set to White Rock.
- Sales window: the 12 complete months ending two months before the run month (the sold feed lags several weeks).
- Days to sell = sold date minus list date, both as Pacific-time calendar dates (Lofty's `daysOnList` is days until today, so it is not used).
- Sales are bucketed by month in Pacific time, exactly as Lofty does. Checked 2026-10-30: monthly counts and median sold prices for Oct 2025 to Aug 2026 match Lofty's `soldPriceStat` feed with 0 differences, and days to sell matches Lofty's own average (110.3 vs 110.0 over 11 sales).
- `refresh.js` exits 2 unless the page header count, the parsed cards and the distinct listing links all agree (every card is counted; identical units at one address are separate listings), and 3 if the Lofty request cannot be found. It saves Lofty's own monthly statistics (`stat.json`) and `build.py` reconciles monthly sale counts against them.
- `build.py` safety gate: if any headline figure moves more than 25%, it writes `data/market.pending.json`, changes nothing else, and exits 4. Review, then re-run with `--force`.
- The loader only writes allow-listed characters (letters, digits, `$ , . -` and spaces, max 40) with `textContent`, so a bad feed cannot inject markup.
- If the branch is renamed or deleted, update `FEED_URL` in `build.py` and re-paste the code once.
- Scheduled: 8:00 AM Pacific on the 5th of each month. The static fallback numbers can be refreshed occasionally by re-pasting the code.

- Wording rule: the Market snapshot text says a property type is "the bulk of the market" only when it is at least 55% of the past year's sales; otherwise "the largest group".
- `tools/page-build/city_page.py` refuses to write a page containing an unrendered `{...}` placeholder (a string missing its f prefix once showed a literal `{NH}` in two card titles).

- Richmond (`richmond`): `node refresh.js richmond`, then `python3 build.py richmond`. Loader: `richmond-market-loader.txt`.
